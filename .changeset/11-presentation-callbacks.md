**Customize how a review reads, from library code.** `publishSarifReview` and `validateSarifReview` accept `options.presentation` (the new `IReviewPresentation`), a set of functions that return the Markdown of named elements: `finding`, `attribution`, `alternatives`, `fileAddition`, `fileDeletion`, `manualEdit` (an edit made by hand), `lifecycleNote` (how a suggestion pull request is accepted), `companionIndex` (the review's index of its suggestion pull requests) and `companionReference` (a suggestion pull request's section of the review). Each receives the element's data, its built-in Markdown (`markdown`) and the fragments the result must keep (`required`); elements left out keep the built-in presentation, which is unchanged. Each context has its own public type, such as `IFindingPresentationContext` or `ICompanionIndexPresentationContext`.

A callback changes how an element reads, never what is published, where, or how it is identified: the tool still places every finding, adds native suggestion blocks exactly as validated, adds the review's publication marker and each suggestion pull request's marker last, and counts the customized text toward the size limits. Results are read with a CommonMark + GFM parser and refused with a `TypeError`, before anything is written, when they are not a non-blank string, omit or hide a required fragment (each must be shown as itself, at its own occurrence), could open a suggestion block, leave a code fence or raw HTML open, contain marker text, add raw HTML, a link reference definition, an invisible character or a link of their own that reuses the text of a link the element presents, or (for `attribution`) span several lines. The companion index and sections must keep every companion's `link`, so each number leads to its own pull request; they run once while the review is prepared, with placeholder numbers, and once more with the real numbers when the review is composed. Callbacks are not part of the publication identity: a retry reuses what was recorded and calls none. There is no command-line equivalent.

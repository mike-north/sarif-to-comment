"sarif-to-comment": minor
---

Close companion suggestion pull requests whose original pull request has ended. `closeSuggestionPullRequests` in the library and `sarif-to-comment close-suggestion-prs --repo OWNER/REPO` in the CLI check the open pull requests of the repository's `suggestion-pr/` branches, which must carry its suggestion label, or with `originalPullNumber` / `--original N` only the pull requests referencing that original. A pull request counts as a suggestion only when its description carries the hidden suggestion marker exactly in its canonical form; titles are never read. It is closed only after its original has been read and found merged or closed, and after the suggestion has been read again and verified (still open, same marker and label, its own proposal branch in the same repository). An original that can't be read is reported `unverified` and never treated as ended. Everything is read before the first close; `dryRun` / `--dry-run` closes nothing. Closing is the only change: branches are never deleted and nothing else is edited. Each pull request gets a result (`closed`, `would-close`, `already-closed`, `left-open`, `unverified`, `permission-limited`, `failed`, `not-conforming`, `other-owner` or `unlabeled`), and the run is `complete` (CLI exit 0), `permission-limited` (exit 2: refused closes are reported apart from failures) or `incomplete` (exit 3: safe to run again). Suggestion labels containing a comma are refused, since GitHub's label filter would read them as several labels.
